# Sheets to Tables Changelog

Release notes for the Sheets to Tables Craft CMS plugin.



## 1.2.0 - 2024-04-14

### Added
- Added support for Craft 5.

### Changed
- Updated PhpSpreadsheet to 2.0 (on supported environments).
- The plugin’s Twig extension name is now translatable.



## 1.1.0 - 2022-07-19

### Added
- Added support for Craft 4.



## 1.0.0 - 2018-11-16

- Initial release.

### Added
- Twig function to convert an excel file into an HTML `<table>`.
